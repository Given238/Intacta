# Demo Script

## Terminal shortcuts
| Key | Action |
|-----|--------|
| `` ` `` (backtick) | Toggle the typed-utterance input (demo fallback for voice). Enter sends, Esc closes. |
| `~` (Shift + backtick) | Toggle the debug overlay (route, socket, audio state, language, pairing). |

- Keys are ignored while an input or textarea is focused.
- On the tablet (no keyboard), open the terminal with `?dev=1` (e.g. `https://<domain>/terminal?dev=1`):
  the typed input and the debug overlay stay visible permanently.
- Ctrl+Shift+T / Ctrl+Shift+D are not used: Chrome intercepts them.
